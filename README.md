# Tapaswini Pradhan Portfolio

A professional recruiter-focused portfolio website built with Next.js, TypeScript, and Tailwind CSS.

## Project Overview

This portfolio highlights Tapaswini Pradhan's frontend development experience, skills, professional experience, and sample projects. The site includes responsive design, dark/light mode, accessible UI, semantic structure, and SEO-friendly metadata.

## Technologies

- Next.js App Router
- TypeScript
- Tailwind CSS
- React
- Lucide React icons

## Local Setup

1. Install dependencies:

```bash
npm install
```

2. Start development server:

```bash
npm run dev
```

3. Open in browser:

```bash
http://localhost:3000
```

## Build Command

```bash
npm run build
```

## Deploy to Vercel

1. Create a Vercel account and install Vercel CLI if needed.
2. From the project folder, run:

```bash
npx vercel
```

3. Follow the prompts and deploy the project.

## Add Resume

Place your actual resume file at:

- `public/resume/Tapaswini-Pradhan-Resume.pdf`

The site already includes the `resume` folder and a placeholder path.

## Replace Placeholders

Update these values in the project as needed:

- Email placeholder in `components/ContactSection.tsx` and `components/Footer.tsx`
- Live demo links in `components/ProjectsSection.tsx`

## Vercel Deployment Instructions

1. Push the repository to GitHub.
2. Open Vercel and create a new project.
3. Select the `tapaswini-portfolio` repository.
4. Keep defaults for Framework Preset and Root Directory.
5. Deploy.

No extra configuration is required for this Next.js app.
